# GCSE Maths curriculum map — source file (edit this, then run: node tools/build-gcse-map.js)
#
# Structure follows the six content areas of the DfE national GCSE Maths subject content
# (Number · Algebra · Ratio, proportion and rates of change · Geometry and measures · Probability · Statistics).
# Topics and knowledge points are teaching-level groupings written for this project, NOT the official statement wording.
#
# Line formats
#   @ AREA_ID ~ Area name
#   # TOPIC_ID ~ Topic name
#   POINT_ID ~ Knowledge point ~ Tier ~ coverage (optional)
# Tier:  F = Foundation and Higher   H = Higher only   (tier labels are approximate; check against your exam board)
# Coverage: game:regex;game:regex   — a regex over the game's skill names (levels grouped by name). The build fails if a
#           regex matches nothing, so a renamed level cannot silently break the map.
# Point IDs are permanent. Never rename one once students' data uses it; change the name only.
